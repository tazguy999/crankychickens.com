Workflow 5 — AI Ops Score Computation
🥚 NEST SCORE — repeatability
Any runs → 1
I/O defined → 2
3+ consistent → 3
10+ consistent → 4
🐔 FLOCK SCORE — reliability
rate < 50% → 1
rate < 20% → 2
rate < 5% → 3
event-driven → 4
0% · 20 runs → 5
// signals that count as runs per skill full_code → write-spec, type-resolution, sprite-gen, feature-build orbital → sprite-gen, type-resolution config_only→ sprite-gen, feature-build, type-resolution // dings from delivery log dingedSkills[] intervention_rate = dings / total_runs // auto-computed verdicts READY : runs ≥ 10 AND rate == 0 AND nest ≥ 4 REGRESS : rate > 0.4 HOLD : everything else
