Framework Synthesis

Nick × Ng

Ng gives you a spectrum of autonomy. Nick adds a second axis — whether the work is understood well enough to automate. You can't move right until you've moved up.

Ng's Framework — One Axis
L0
Single prompt
One input, one output. No memory, no tools. manual
L1
Chain
Fixed sequence. Output feeds next input. scripted
L2
Branching
If/else routing from LLM output. Deterministic orchestrator. scripted
L3
Tool use
LLM calls external systems. Real state changes. Cranky Chickens pipeline. agentic
L4
LLM orchestrator
LLM decides what to call next. hoppy-iterate. Error compounding risk. agentic
L5
Multi-agent
LLMs orchestrate LLMs. Long-horizon. Self-directed. frontier

Ng's gap: assumes the work is already understood. Skips whether it should be automated at all.

How They Connect
Ng's L3 = Nick's Verified Process + Reliable Automation
You can't reach L3 without hitting ●●●● on Process first. Most teams jump L1 to L3 and wonder why automation breaks. They skipped Standardized.
hoppy-iterate is Ng's L4 with Process ●●●○
LLM orchestrator hitting ADO + GH + Notion. Impressive technically. But the SOP lives in your head. Standardized, not Verified. The grid says: reduce automation or accept the risk explicitly.
Graduation = movement on both axes simultaneously
Nest score = Process maturity. Flock score = Automation reliability. Graduation requires both bars full. Ng never says this. Nick built it into the system.
Nick's step 0 is the missing prerequisite to Ng's entire framework
Ng starts at L0. Nick starts earlier — do it manually until the pattern is visible. Without that, L0 is just guessing what to automate. Nick's step 0 is the foundation Ng's pyramid sits on.
