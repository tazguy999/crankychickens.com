## Scoring System

| Range | Status | What it means |
|---|---|---|
| 0–30 | Supervised | Nick reviews every output before anything runs |
| 31–60 | Semi-autonomous | Agent runs, Nick approves before merge |
| 61–90 | Trusted | Agent commits to kids-preview, Nick reviews in Mission Control |
| 91–100 | Fully autonomous | Agent merges directly (FS probably never gets here) |

Scores increase by passing challenges. Scores decrease by:
- Producing broken code that ships (-10)
- Misinterpreting kid intent (-5)
- Failing a previously-passed challenge (-3)
- Escalating unnecessarily (-2)
